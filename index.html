Module 1.1 · Basics & Assumptions
LOS 1.a

Investment Problems & the Regression Process

Types of investment problems addressed by multiple linear regression, and the regression process.

A one-factor regression is usually inadequate for the complexity of financial and economic relations. Multiple linear regression models the linear relationship between one dependent variable and two or more independent variables.

Three uses

1. Identify relationships

Exploratory analysis of factors that influence small-cap returns; does the 3-factor Fama-French model (market, size, style) explain cross-sectional returns?

2. Forecast variables

Forecast a company's cash flows; predict the probability of default.

3. Test existing theories

Do high intangibles on the balance sheet (beyond other known factors) explain credit risk premiums?

The model and the process

General model
Yi = b0 + b1X1i + b2X2i + … + bkXki + εi
Estimated: Ŷi = b̂0 + b̂1X1i + … + b̂kXki
Residual: ε̂i = Yi − Ŷi (observed − predicted)

Y = dependent (response) variable; X = independent variables (predictors); b0 = intercept; bj = slope coefficients; ε = error term. The method (OLS) chooses the intercept and slopes that minimize the sum of squared errors.

p-value approach (new at Level II)

The p-value is the smallest significance level at which H0 can be rejected. To test H0: bj = 0 vs Ha: bj ≠ 0 (the t-test from Level I), compare p-value with α: p < α → reject H0; p > α → fail to reject. The lower the p-value, the stronger the evidence.

Observed points (blue), fitted line (gold) and residuals ε̂ᵢ = Yᵢ − Ŷᵢ (red): OLS chooses the line that minimizes the sum of squared residuals.

Definition of terms in the general model

SymbolMeaning
Yii-th observation of the dependent variable Y, i = 1, 2, …, n
XjIndependent variables, j = 1, 2, …, k
Xjii-th observation of the j-th independent variable
b0Intercept term
bjSlope coefficient for each independent variable
εiError term for the i-th observation

Level I → Level II
Level I: simple regression + t-test of slope. Level II: alternatively use the p-value (smallest significance level at which H0 can be rejected): p < α → reject H0; p > α → cannot reject.

Key Concepts (Schweser summary)

Key Concepts

Multiple regression models can be used to identify relationships between variables, forecast variables, or test existing theories.

Formulating the Model & Interpreting Coefficients

Formulate a multiple regression model and interpret estimated coefficients.

Arnott & Asness (2003): future 10-year real earnings growth of the S&P 500 (EG10) explained by the trailing dividend payout ratio (PR) and yield curve slope (YCS = 10-year T-bond yield − 3-month T-bill yield at start of period). All variables in %; annual data, 46 observations.

Estimated equation
EG10 = −11.6% + 0.25·PR + 0.14·YCS
CoefficientStandard error
Intercept−11.6%1.657%
PR0.250.032
YCS0.140.280

How to read the results

  • Intercept: value of Y when all X's = 0. Here: PR = 0 and YCS = 0 → EG10 = −11.6%.
  • Slope (partial slope coefficient): estimated change in Y for a 1-unit change in that X, holding the other independent variables constant.
  • PR: +1% payout → +0.25% growth, holding YCS constant. YCS: +1% slope → +0.14% growth, holding PR constant.
Why coefficients change

Simple regression Y = 2.0 + 4.5X1: +1 unit X1 → +4.5 in Y. Add X2 and the slope on X1 becomes 2.5 — expected, because X1's effect is now measured holding X2 constant.

✅Exam trap (Module Quiz 1.1 Q2): for Y = 2.30 + 5.02X1 − 4.55X2, you can NOT add slopes (5.02 + 2.30 = 7.32 is wrong). Each slope is interpreted separately, holding the other constant.

Worked comparison: adding a second variable

Simple vs multiple
Simple: Y = 2.0 + 4.5X1 → X1 +1 unit ⇒ Y +4.5 units
Multiple: Y = 1.0 + 2.5X1 + 6.0X2 → X1 +1 unit ⇒ Y +2.5 units, holding X2 constant

The slope on X1 changed from 4.5 to 2.5 when X2 was added. We expect this when a second variable is included.

Key Concepts (Schweser summary)

Key Concepts

General model: Yi = b0 + b1X1i + … + bkXki + εi. Intercept b0 = value of Y when all X = 0. Slope bi = estimated change in Y for a 1-unit change in Xi, holding all other X constant.

Assumptions & Residual Plots

Explain the assumptions of multiple regression and interpret residual plots showing violations.

Five assumptions

1. Linearity

Linear relationship between Y and the X's.

2. Homoskedasticity

Variance of residuals is constant for all observations.

3. Independence of errors

Residual of one observation is uncorrelated with another's (no serial correlation).

4. Normality

Residuals are normally distributed.

5. Independent variables are not random & not exactly collinear

No exact linear relation between two or more X's (or combinations of X's).

Residual plots give a preliminary indication of violations; formal tests for the last three (homoskedasticity, independence, collinearity) come later (LOS 1.h–1.j).

Q-Q plot

A normal quantile-quantile (Q-Q) plot compares a variable's distribution with the normal distribution. Plot standardized residuals: if normal, they lie along the diagonal. Recall that 5% of normal observations lie below −1.65 standard deviations.

Example — office rent model (n = 191)

rent = b0 + b1age + b2distance + b3restaurant + ε (rent per sq ft; age in years; distance to metro in miles; restaurants within walking distance).

Key Concepts (Schweser summary)

Key Concepts

Assumptions: (1) linear relationship between Y and X; (2) residuals normally distributed; (3) constant variance of error terms; (4) residuals of different observations uncorrelated; (5) X's not random and no exact linear relation among X's. Residual plots give only a preliminary indication of violations.

LOS 1.d

ANOVA, R², Adjusted R², AIC & BIC

Evaluate how well a model explains the dependent variable using ANOVA and goodness-of-fit measures.

ANOVA splits total variation in Y into explained (regression) and unexplained (error) parts.

SourcedfSSMS
RegressionkRSS (explained)MSR = RSS/k
Errorn − k − 1SSE (unexplained)MSE = SSE/(n − k − 1)
Totaln − 1SST
Coefficient of determination
R² = (SST − SSE)/SST = explained variation / total variation = RSS/SST

R² is the % of variation in Y collectively explained by all X's (R² = 0.63 → model explains 63%). Problem: R² almost always rises as variables are added, even insignificant ones (overfitting).

Adjusted R²
R²a = 1 − [ (n − 1)/(n − k − 1) × (1 − R²) ]
  • R²a ≤ R²; it can be negative when many X's have no explanatory power.
  • Adding a variable: R² rises; R²a may rise or fall. If |t| of the new coefficient > 1.0 → R²a rises; if < 1.0 → falls.
  • R²a penalizes overfitting but does not show quality of fit or significance of slopes — use the F-test (LOS 1.e).
Example — R² and adjusted R²

60 monthly obs, k = 5, SST = 460, SSE = 170: R² = 290/460 = 63.0%; R²a = 1 − (59/54)(1 − 0.63) = 59.6%. Add 4 variables (k = 9), R² = 65.0%: R²a = 1 − (59/50)(0.35) = 58.7% (lower) → prefer the 5-variable model.

Information criteria (compare models for the same Y; lower is better)

AIC and BIC
AIC = n·ln(SSE/n) + 2(k + 1)
BIC = n·ln(SSE/n) + ln(n)·(k + 1)
  • AIC → use when the goal is a better forecast. BIC → use for better goodness of fit.
  • k is a penalty; because ln(n) > 2 even for small samples, BIC penalizes overfitting more.
Example — rent model

Bonus: standard error of estimate (SEE)

SEE
SEE = √[ SSE / (n − k − 1) ]

SEE is the standard deviation of the differences between estimated and actual values of Y. Violated assumptions affect SEE; a strong relationship with small SSE means small individual estimation errors.

Variation decomposition for one observation: SST (total: point to mean of Y) = SSR/RSS (explained: fitted line to mean) + SSE (unexplained: point to line).

ANOVA formulas (Key Concepts)

Definitions
MSR = RSS / k ; MSE = SSE / (n − k − 1) ; R² = RSS / SST
SST = RSS + SSE (total = explained + unexplained)

Quiz 1.2 worked calculations

Adjusted R² of the full model

SSE = 4,320, SST = 9,105 → RSS = 4,785; n = 65, k = 4. R² = 4,785/9,105 = 0.53. R²a = 1 − (64/60)(1 − 0.5255) = 0.494 ≈ 0.50.

BIC comparison

BICU = 65×ln(4,320/65) + ln(65)×5 = 273 + 21 = 294. BICR = 65×ln(5,105/65) + ln(65)×3 = 284 + 12 ≈ 296. Lower BIC = better goodness of fit → the full model.

Key Concepts (Schweser summary)

Key Concepts

ANOVA table assesses usefulness of the independent variable(s). AIC and BIC compare competing models for the same dependent variable: AIC → better forecast; BIC → better goodness of fit; lower is better.

Joint Hypothesis Tests (F-test)

Formulate hypotheses on two or more coefficients and interpret joint tests.

Nested models: a full (unrestricted) model and a restricted model containing only a subset of its variables. Unrestricted: Y = b0 + b1X1 + b2X2 + b3X3 + ε. Restricted: Y = b0 + b1X1 + ε.

Joint F-test
H0: b2 = b3 = 0 vs Ha: at least one of b2, b3 ≠ 0
F = [(SSER − SSEU)/q] / [SSEU/(n − k − 1)] with q and (n − k − 1) df
Reject H0 if F > Fcritical

q = number of excluded variables in the restricted model; k = independent variables in the full model. The F-test asks whether the relative fall in SSE from adding q variables is statistically justified. It is preferred to individual t-tests because X's are usually correlated, so the joint test is more meaningful.

CircumstanceHypothesisStatisticReject H0 if
Full model works (overall fit)H0: b1 = … = bk = 0; Ha: at least one ≠ 0F = MSR/MSE, df k and n − k − 1F > Fc
Each slope ≠ 0H0: bj = 0t = (b̂j − Bj)/sb̂j, df n − k − 1|t| > |tc|
A group of X's contributes (joint)H0: b2 = b3 = 0F with q and n − k − 1 dfF > Fc

Overall-fit special case: all X's excluded (q = k), so SSER = SST and F = (RSS/k)/(SSE/(n − k − 1)) = MSR/MSE.

Example — rent model joint test (5%)

Unrestricted: k = 3, SSE = 13,550.64; restricted: SSE = 32,627.29; n = 191. F = [(32,627.29 − 13,550.64)/2] / [13,550.64/(191 − 3 − 1)] = 131.63. Critical F (2 and 187 df) = 3.04 → reject H0: at least one excluded slope differs from 0.

⚠️PROFESSOR'S NOTE: the F-test of 'all coefficients = 0' is always a one-tailed (right-tail) test even though H0 contains an equals sign — a classic Level II mistake.

Alternative forms of the F-statistic

Joint F
F = [(SSER − SSEU)/q] / [SSEU/(n − k − 1)]
Overall model (q = k, SSER = SSTU): F = [(SSTU − SSEU)/k] / [SSEU/(n − k − 1)] = (RSSU/k) / [SSEU/(n − k − 1)]
General H0: bi = bj = … = bq = 0; Ha: at least one slope of excluded variables ≠ 0
F-distribution (illustrative shape): the F-test is one-tailed — reject in the right tail.

LOS 1.f

Predicting the Dependent Variable

Calculate and interpret a predicted value from an estimated model and assumed X values.

Plug forecasted X values into the estimated equation: Ŷ = b̂0 + b̂1X̂1 + … + b̂kX̂k.

  • Use the intercept and all estimated slopes — even if some are not statistically significant.
  • Alternatively drop the insignificant X and re-estimate — but the remaining coefficients will most likely change.
Example — EG10 prediction

PR = 50%, YCS = 4%: EG10 = −11.6% + 0.25(50%) + 0.14(4%) = 1.46% predicted 10-year real earnings growth.

Worked example — insignificant X2

Prediction with a non-significant variable

Estimated Ŷ = 6 + 2X1 + 4X2; only X1 is significant (fail to reject b2 = 0). Forecasts X1 = 0.6, X2 = 0.8 → Ŷ = 6 + (2 × 0.6) + (4 × 0.8) = 10.4. You use the complete model. Alternatively drop X2 and re-estimate, but the X1 coefficient will most likely change.

Key Concepts (Schweser summary)

Key Concepts

Predicted Ŷ = b̂0 + b̂1X1 + … + b̂kXk, using the estimated intercept and all slope coefficients regardless of significance.

Model Misspecification

How misspecification affects results and how to avoid common forms.

Specification = selecting the independent variables and any transformations. Principles: variables have an economic rationale; the model is parsimonious; functional form is correct; it performs well out of sample; and it does not violate key assumptions.

MisspecificationDescriptionEffect
Omitted important variablePer theory, should be included but is notBiased and inconsistent parameters; may cause serial correlation or heteroskedasticity
Inappropriate variable formRelationship is non-linear (e.g., use ln M, not M)May cause heteroskedasticity
Inappropriate scalingVariables need transformation (e.g., common-size by sales/total assets)May cause heteroskedasticity or multicollinearity
Data improperly pooledDifferent economic regimes pooled (unstable slopes)May cause heteroskedasticity or serial correlation

Chinese-stock example (Wang & Xu 2004), 72 monthly obs

Portfolio of Chinese stocks: R = monthly return; B = portfolio beta; lnM = natural log of market cap; lnPB = natural log of price-to-book; FF = free float = shares available for trading by the public / total shares outstanding (see the equations below).

  • #1 Omit lnM: if correlated with remaining X's → error correlated with X's → coefficients biased and inconsistent, tests and predictions unreliable. If uncorrelated → only the intercept is biased.
  • #2 Not transforming: use M instead of ln(M) although ln M is what is linear in returns.
  • #3 Scaling: using number of tradable shares instead of proportion → similar firms with very different FF.
  • #4 Pooling: one regression over 6 years when the relationship differs across two 3-year sub-periods.
⚠️PROFESSOR'S NOTE: 'omission' means a variable that should be included is missing. Dropping one of two highly correlated X's to fix multicollinearity is not omission.

Three assumption violations — ask four questions of each

(1) What is it? (2) Effect? (3) How to detect? (4) How to correct? — for heteroskedasticity, serial correlation, multicollinearity (next three LOS).

Warm-up example: predicting P/E

Cross-sectional regression of P/E on fundamentals suggested by valuation theory: dividend payout ratio (DPO), growth rate (G) and beta (B). Specification = selecting the explanatory variables and any transformations of them.

Heteroskedasticity

Types of heteroskedasticity and effect on statistical inference.

Heteroskedasticity: variance of residuals is not the same across observations (some subsamples are more spread out).

Unconditional

Not related to the level of the X's. Violates equal variance but usually causes no major problems.

Conditional

Related to the level of the X's (e.g., variance grows as X grows). Causes significant problems.

Effects of conditional heteroskedasticity

  • Standard errors are unreliable — for financial data usually underestimated → t-stats too large → Type I errors.
  • The F-test for the overall model is unreliable.
  • Coefficient estimates remain consistent and unbiased.
Figure 1.4 style — CONDITIONAL HETEROSKEDASTICITY: residual variance grows with X (fan shape).

Detection

  1. Scatter plot of residuals vs X (e.g., fund-return example: residual spread widens as the S&P return rises → conditional heteroskedasticity).
  2. Breusch-Pagan (BP) chi-square test: regress squared residuals on the original X's (û² = a0 + a1X1 + … + ε). H0: no heteroskedasticity (all aj = 0).
Breusch-Pagan
BP = n × R²resid ~ χ² with k df
One-tailed, right-side test: reject H0 if BP > χ² critical
R²resid = R² of the second regression (squared residuals on the X's)
Example — BP test

5 years monthly (n = 60), R² of squared-residual regression = 8%, one X: BP = 60 × 0.08 = 4.8 > 3.841 (χ², 1 df, 5%) → reject: conditional heteroskedasticity present.

Correction

Use robust standard errors (White-corrected / heteroskedasticity-consistent), then recompute t-statistics with the original coefficients.

Serial Correlation

Explain serial correlation and its effect on inference.

Serial correlation (autocorrelation): residuals are correlated with each other. A serious problem mainly in time-series regressions.

  • Positive: a positive residual raises the probability of a positive residual next period.
  • Negative: a positive residual raises the probability of a negative one next period.

Effects

  • Model parameters: if a lagged Y is an X, residual autocorrelation makes slope estimates inconsistent; with no lagged dependent variable, slopes stay consistent.
  • Standard errors: positive first-order serial correlation (most common in financial data) → SEs too small → t- and F-statistics too large → Type I errors.

Detection

  • Durbin-Watson (DW): single lag (p = 1) only.
  • Breusch-Godfrey (BG): multiple lags. Regress residuals on the original X's plus p lagged residuals (ût = a0 + a1X1t + … + ρ1ût−1 + … + et). H0: ρ = 0 (no serial correlation). Statistic ~ F with p and n − p − k − 1 df (p = lags tested); right-tail, reject if BG > Fc.
0 → dLdL → dUdU → 4 − dU4 − dU → 4 − dL4 − dL → 4
Reject H0: positive autocorrelationInconclusiveDo not reject: no evidence of autocorrelation (DW ≈ 2)InconclusiveReject H0: negative autocorrelation
Durbin-Watson decision zones (values between 0 and 4).

Correction

Newey-West robust standard errors (heteroskedasticity- and autocorrelation-consistent), then recompute t-statistics.

⚠️PROFESSOR'S NOTE: serial correlation in financial data (not residuals) is a pattern that can be modeled — see the Time-Series Analysis reading.

Multicollinearity

Explain multicollinearity and its effect on regression analysis.

Multicollinearity: two or more X's (or linear combinations of three or more) are highly correlated. It inflates standard errors and lowers t-stats.

  • Coefficients: still consistent, but imprecise and unreliable.
  • Standard errors: too high (credit can't be assigned precisely) → t low → Type II errors.

Detection

  1. Classic symptoms: R² high and F-test significant, but t-tests show none of the individual coefficients significant (common variation explains Y, individual effects "wash out").
  2. VIF: regress Xj on the other X's to get R²j.
Variance inflation factor
VIFj = 1 / (1 − R²j)
VIFR²jMeaning
10Xj uncorrelated with other X's
> 5> 80%Warrants further investigation
> 10> 90%Severe multicollinearity

Correction

Most common: omit one or more correlated X's. Alternatives: use a different proxy for one X, or increase the sample size.

Detect: high R² + significant F but insignificant t's; VIF > 5 investigate, > 10 severe. Correct: omit variable(s), different proxy, larger sample.

Influential Data Points

Influence analysis and methods of detecting influential data points.

Outliers = extreme observations of the dependent (Y) variable. High-leverage points = extreme observations of the independent (X) variables. Influential points = extreme observations that, when excluded, cause a significant change in model coefficients (and poor out-of-sample performance). Not all outliers/high-leverage points are influential.

High leverage: leverage hij

  • Distance of the observation of X from its sample mean; ranges 0 to 1; higher → more potential influence. Sum of leverages = k + 1.
Rule
Potentially influential if leverage > 3(k + 1)/n (three times the average)

Outliers: studentized residuals

  1. Estimate the model on n observations; delete one observation at a time and re-estimate with n − 1 (for all observations).
  2. Residual: e*i = Yi − Ŷi* (actual Y of the deleted observation minus its prediction from the model estimated without it).
  3. Studentized residual ti* = e*i / se*.
  4. Compare |ti*| with critical t, df = n − k − 2; if larger → potentially influential.

Cook's distance (Di) combines leverage and outlier information: Di > 0.5 → investigate further; Di > 1 (the course slide also cites a k/n-based cutoff) → high likelihood of an influential observation.

💡PROFESSOR'S NOTE: focus on interpreting studentized residuals from software, not calculating them.

What to do

Check for an input error (fix or delete), or the observation is valid but the model is incomplete (omitted variables). Analysts can also winsorize the data to limit outlier impact.

Example — IPO outliers

24 IPOs, k = 3 → df = 24 − 3 − 2 = 19; tc (5%, two-tailed) = 2.09. Observations 3 (2.2310), 19 (−3.0165) and 23 (2.1860) exceed 2.09 in absolute value → outliers.

Qualitative Independent Variables (Dummies)

Formulate and interpret a model with dummy variables.

Dummy variables take 0 or 1 to capture a binary qualitative effect (e.g., January dummy in stock-return regressions). The coefficient measures the difference in Y for that category relative to the omitted (reference) class.

Rule
To distinguish n classes, use (n − 1) dummies — otherwise an exact linear relation (perfect multicollinearity) violates the assumptions.
TypeModelEffect
Intercept dummyY = b0 + d0D + b1X + εIntercept shifts from b0 to b0 + d0 when D = 1
Slope dummy (interaction)Y = b0 + b1X + d1D·X + εSlope changes from b1 to b1 + d1
CombinationY = b0 + d0D + b1X + d1D·X + εBoth shift
Example — quarterly EPS

EPSt = b0 + b1Q1 + b2Q2 + b3Q3 + ε (Q4 omitted). b0 = average Q4 EPS. With b0 = 1.25, b1 = 0.75, b2 = −0.20, b3 = 0.10 (40 quarters): Q1 = 2.00, Q2 = 1.05, Q3 = 1.35, Q4 = 1.25. These are also the forecasts for next year's quarters.

Equations and their two states

TypeEquationIf D = 0If D = 1
Intercept dummyY = b0 + d0D + b1X + εY = b0 + b1X + εY = (b0 + d0) + b1X + ε (intercept shifts by d0, positive or negative)
Slope dummy (interaction)Y = b0 + b1X + d1(D×X) + εY = b0 + b1X + εY = b0 + (b1 + d1)X + ε
BothY = b0 + d0D + b1X + d1(D×X) + εY = b0 + b1X + εY = (b0 + d0) + (b1 + d1)X + ε

Exact wording: the dummy coefficient indicates the difference in Y for the category represented by the dummy relative to the average value of Y for all classes except the dummy class. A slope dummy is the interaction term between the dummy and the continuous variable.

Quarterly EPS — predicting next year

EPSt = b0 + b1Q1t + b2Q2t + b3Q3t + εt (Qit = 1 if quarter i, else 0). 10 years = 40 observations. Estimated: EPS = 1.25 + 0.75Q1 − 0.20Q2 + 0.10Q3. To predict Q1 of next year set Q̂1 = 1, Q̂2 = 0, Q̂3 = 0: EPSQ1 = 1.25 + 0.75(1) − 0.20(0) + 0.10(0) = 2.00. This simple model uses the average EPS for each quarter over the past 10 years as the forecast.

Key Concepts (Schweser summary)

Key Concepts

Dummy variables capture binary independent variables (intercept dummy, slope dummy, or both). Use n − 1 dummies for n classes.

Logistic Regression

Formulate and interpret a logistic regression model.

A qualitative dependent variable (binary, e.g., default = 1) needs logit, because OLS forecasts can fall below 0 or above 1. Transform probability to odds = p/(1 − p) (p = 0.80 → 4-to-1), then take the natural log (log odds).

Logit model
ln[p/(1 − p)] = b0 + b1X1 + … + bkXk + ε = y
odds = ey
p = odds/(1 + odds) = 1/(1 + e−y)
  • Residuals assumed logistic (like normal, fatter tails). Uses: probability of default, of a merger.
  • Coefficients estimated by maximum likelihood (MLE).
  • Intercept = log odds when all X = 0. A slope = change in log odds per 1-unit change in X holding others constant — not a change in probability (model is nonlinear; to see the probability effect, start at average X and change one X by 1 unit).
  • Pseudo-R² (if reported) is only for comparing models with the same dependent variable.
Example — dividend increase (36 firms)

y = −3.445 + 0.332 Age + 12.33 FCFE/MCap + 3.21 Cash/TA (Age p = 0.412 not significant; others p < 0.05). Intercept: odds = e−3.445 = 0.0319 → p = 3.09%. At mean X (3.2, 0.08, 0.03): y = −1.2999 → p = 21.42%. FCFE/MCap 0.08 → 0.09: y = −1.1766 → p = 23.57% (+2.15%).

Likelihood ratio (LR) test for nested logit models

LR test
LR = −2 × (LLrestricted − LLunrestricted) ~ χ² with q df
H0: the restricted model is better (excluded slopes = 0); reject if LR > χ² critical

Log-likelihood is always negative; values closer to 0 = better fit. q = number of variables removed.

✅Exam trap (Quiz 1.4 Q4): logit → LR test with a chi-square (not F); slopes are changes in log odds (not probability).
Logistic (S-shaped) curve: the predicted probability stays between 0 and 1 (slide example: probability of promotion vs work experience).

LR test — Module Quiz 1.4 Q5

Unrestricted (5 X's) LL = −212.44; restricted (2 removed) LL = −216.22; q = 2; critical χ² = 5.99. LR = −2(−216.22 − (−212.44)) = 7.56 > 5.99 → reject H0 (excluded coefficients = 0): the excluded variables contribute to explaining Y.

LR test — slide example

Model A: ln(P/(1−P)) = b0 + b1X1 + b2X2 + b3X3 + ε vs Model B with b2 = b3 = 0. H0: the smaller restricted model is better; Ha: at least one of b2, b3 ≠ 0. Reject if LR > χ² critical (q df). Use the chi-square table (row df = q).

Key Concepts (Schweser summary)

Key Concepts

Qualitative dependent variable → logit (log odds), estimated by maximum likelihood. Slope = change in log odds per 1-unit change in X, holding others constant. Compare nested logit models with the LR test (chi-square, q df). Pseudo-R² only compares models with the same dependent variable.
